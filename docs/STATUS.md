# Фактическое состояние v0.6 — передача работы

## Продолжение 4 октября, ночной проход

Дополнение 5 октября: реализован захват триггерами через отдельный HandInput.
Editor test подтвердил Z/X → bound actions → два разных тела, удержание,
отпускание и потерю трекинга без самопроизвольного повторного захвата.
Исправлена конкретная ошибка PhysicsAsset: радиусы/длины вторичных тел были
умножены на FBX bone scale=100. После ремонта размеры пряди ~3×4×5 см вместо
~157×175×208 см. Четыре группы прошли проверку передачи физического вращения
видимым костям (около 2,8° волосы / 3,0° одежда / 0,46° тело / 3,72° хвост
при контрольном angular pulse). Это не подтверждает естественность реальных касаний.
Журнал: evidence/04/editor_corrected_physics_test.log. Проверки пакета продолжаются.

Свежие ReactFace/Hand/Cheer уже прошли MCP QA и импортированы: максимум ошибки
0,071/0,166/0,679 мм; пять прежних клипов прошли регрессию, root/feet drift=0.
Причина прежнего FAIL установлена: разрыв twist предплечья между целыми кадрами
при world-rest ориентации запястья. Перенос roll предплечья устранил разрыв;
допуски не увеличивались. Импорт сохранил skeleton/PhysicsAsset/material slots,
246 костей и исходные морфы, итог 67 морфов. Маршрутизация зон обновлена.

Встроенные Chaos/PhysicalAnimation выбраны для ограниченных физических групп.
Добавлены sphere sweep и ограниченное давление обеих рук, gates/reset и
редактируемые параметры. Editor C++ build прошёл; editor self-test подтвердил
воздействие обеих синтетических рук и отмену ожидающего импульса. Найденные
незарегистрированные PICO menu keys удалены из создаваемых привязок.
Versioned package и полная packaged-регрессия сейчас подготавливаются.
Подробности: [HAND_PHYSICS.md](HAND_PHYSICS.md).

Ниже сохранён исторический статус передачи; его FAIL/неимпортированные клипы
описывают предыдущий checkpoint, а не свежий экспорт.

Дата: 4 октября 2026. Правила: [AGENTS.md](../AGENTS.md).

Выполнены миграция на CharacterProfile, отделение test/soak и editor-only инструментов,
отдельный collision solver, диагностируемый Enhanced Input, явный выбор цели,
Git/LFS и versioned build manifest. Настройки модели доступны через Data Asset;
клипы/PhysicsAsset редактируются в Unreal. Native animation сохраняет проверенные деформации.

MVP не завершён. Подробная передача: [HANDOFF.md](HANDOFF.md).

`evidence/04/editor_reference_build_retry.log`. Windows-пакет компилировался,
но final fingerprint guard отклонил его из-за изменения Scripts во время сборки.
`Builds/Stage1/Windows/build_manifest.json` отсутствует: exe не является
подтверждённым актуальным релизом. Новые packaged проверки не выполнены.

OpenXR IA_Walk уже переведён на зарегистрированные parent-vector `_2D` ключи;
удалены конфликтующие legacy move/turn и несуществующий Index Left X key.
