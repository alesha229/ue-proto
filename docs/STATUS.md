# Фактическое состояние v0.6 — передача работы

Дата: 4 октября 2026. Правила: [AGENTS.md](../AGENTS.md).

Выполнены миграция на CharacterProfile, отделение test/soak и editor-only инструментов,
отдельный collision solver, диагностируемый Enhanced Input, явный выбор цели,
Git/LFS и versioned build manifest. Настройки модели доступны через Data Asset;
клипы/PhysicsAsset редактируются в Unreal. Native animation сохраняет проверенные деформации.

MVP не завершён. Подробная передача: [HANDOFF.md](HANDOFF.md).
Редакторный C++ build после presenter/QA изменений прошёл:
`evidence/04/editor_reference_build_retry.log`. Windows-пакет компилировался,
но final fingerprint guard отклонил его из-за изменения Scripts во время сборки.
`Builds/Stage1/Windows/build_manifest.json` отсутствует: exe не является
подтверждённым актуальным релизом. Новые packaged проверки не выполнены.

OpenXR IA_Walk уже переведён на зарегистрированные parent-vector `_2D` ключи;
удалены конфликтующие legacy move/turn и несуществующий Index Left X key.
Реальный левый стик после исправления ещё не проверен.

Новые ReactFace/Hand/Cheer подготовлены через Blender MCP. Первая версия прошла
геометрическую QA, но визуальная проверка выявила неправильный поворот кистей.
Последний wrist/finger refinement ещё не прошёл корректирующую QA (до45,7мм
на отдельных вершинах перчаток). Старый PASS/FBX нельзя импортировать как финальный.
Черновик открытого Blender сохранён через MCP отдельно:
`evidence/04/blender_mcp/Gratia_reference_unfinished_handoff.blend`.
Unreal assets пока содержат прежние 246 костей/59 морфов/5 клипов.

Ранее math/tracking2tests прошли в `evidence/04/automation/index.json`.
Последний повтор с фильтром `Gratia.` не нашёл тестов и не является PASS.
Подбор/интеграция готового Unreal-плагина для физических костей и взаимодействия
VR-руками — новый запрос пользователя, пока не выполненный.

Аппаратная приёмка остаётся открыта: последнее сообщение пользователя сообщало,
что левый стик не перемещал игрока, а реальные касания были непонятны.
Новая диагностика различает этапы ввода и причины запрета контактов; настольный
synthetic-input test не подтверждает OpenXR-профиль физического контроллера.

Дополнительно потребуется: полноценный ручной AnimGraph вместо native SingleNode,
калибровка contact proxies на видимой поверхности в шлеме и смешанный SteamVR
performance/comfort test. Эти возможности не объявляются выполненными автоматически.
